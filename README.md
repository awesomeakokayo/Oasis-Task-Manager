# Oasis Task Manager

Angular + Spring Boot + PostgreSQL full-stack developer assessment.

## Run

Start PostgreSQL with `docker compose up -d`, run the Spring Boot backend on port 8080, then run the Angular frontend on port 4200.

## Assessment coverage
Registration/authentication, protected task management, task CRUD, priority and due-date sorting, filtering/search, profile data, validation, error handling, PostgreSQL persistence, categories and reminders.

The assessment requires the final codebase to be pushed to GitHub and Oasisdevcloud added as a collaborator.
